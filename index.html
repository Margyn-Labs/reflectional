07Why we can let it act
The trust layer

An agent only acts when the sources agree.

Before Margyn acts, it checks the same fact against independent sources: payments, accounting, commerce, the bank feed, GST filings. When they agree, the action is safe to take alone. When they don't, a person decides. That check is why an agent can update a credit balance without someone signing off on every line.
